### Question 1

证明：**任意混态（mixed state）单量子比特（qubit）的密度矩阵（density matrix）都可以写成如下形式**：
\[
\rho = \frac{I + \vec{r} \cdot \vec{\sigma}}{2}
\]
其中，\(\vec{r} = \{r_1, r_2, r_3\}\) 是一个实三维向量（real three-dimensional vector），满足 \(r_1^2 + r_2^2 + r_3^2 \leq 1\)；\(\vec{\sigma}\) 是泡利矩阵（Pauli matrices）向量 \(\{X, Y, Z\}\)。这个 \(\vec{r}\) 向量被称为该态 \(\rho\) 的布洛赫向量（Bloch vector）。

Prove that **an arbitrary density matrix for a mixed state qubit can be written as**:
\[
\rho = \frac{I + \vec{r} \cdot \vec{\sigma}}{2}
\]
where \(\vec{r} = \{r_1, r_2, r_3\}\) is a real three-dimensional vector with \(r_1^2 + r_2^2 + r_3^2 \leq 1\), and \(\vec{\sigma}\) denotes the vector of Pauli matrices \(\{X, Y, Z\}\). This vector \(\vec{r}\) is called the Bloch vector for the state \(\rho\).


#### 1. **密度矩阵的分解**  
任意一个 2 维的密度矩阵（density matrix）\(\rho\) 都是厄米矩阵（Hermitian matrix），可以写成如下形式：
\[
\rho = \begin{pmatrix} a & b \\ c & d \end{pmatrix}
\]
Any 2-dimensional density matrix \(\rho\) is Hermitian and can be written as:
\[
\rho = \begin{pmatrix} a & b \\ c & d \end{pmatrix}
\]


#### 2. **泡利矩阵和单位矩阵展开**  
如你手写中所示，任何 \(2 \times 2\) 矩阵都能表示为单位矩阵 \(I\) 和三种泡利矩阵（Pauli matrices）\(X, Y, Z\) 的线性组合，这四个矩阵分别为：
As shown in your handwriting, any \(2 \times 2\) matrix can be expressed as a linear combination of the identity matrix \(I\) and the three Pauli matrices \(X, Y, Z\):

- 单位矩阵（Identity matrix）\(I = \begin{pmatrix} 1 & 0 \\ 0 & 1 \end{pmatrix}\)
- 泡利 X 矩阵（Pauli X）\(X = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}\)
- 泡利 Y 矩阵（Pauli Y）\(Y = \begin{pmatrix} 0 & -i \\ i & 0 \end{pmatrix}\)
- 泡利 Z 矩阵（Pauli Z）\(Z = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}\)


#### 3. **密度矩阵的线性展开**  
因此，\(\rho\) 一定可以写作：
So, \(\rho\) can always be written as:
\[
\rho = aI + bX + cY + dZ
\]


#### 4. **利用迹（Trace）来确定系数**  
通过取迹（trace）的方法可以唯一确定这些系数：
We can use the trace to uniquely determine the coefficients:

- 因为 \(\text{Tr}(I) = 2\)，其余的 \(\text{Tr}(X), \text{Tr}(Y), \text{Tr}(Z) = 0\)。
- 系数 \(a = \frac{1}{2}\text{Tr}(\rho)\)
- 系数 \(b = \frac{1}{2}\text{Tr}(\rho X)\)
- 系数 \(c = \frac{1}{2}\text{Tr}(\rho Y)\)
- 系数 \(d = \frac{1}{2}\text{Tr}(\rho Z)\)


#### 5. **布洛赫向量及最终公式（Bloch Vector and Final Formula）**  
我们可以定义布洛赫向量（Bloch vector） \(\vec{r} = (r_1, r_2, r_3)\)，其中
We can define the Bloch vector \(\vec{r} = (r_1, r_2, r_3)\), where:
\[
r_1 = \text{Tr}(\rho X), \quad r_2 = \text{Tr}(\rho Y), \quad r_3 = \text{Tr}(\rho Z)
\]



因此密度矩阵可以重写为：
So, the density matrix can be rewritten as:
\[
\rho = \frac{I + r_1 X + r_2 Y + r_3 Z}{2}
\]


#### 6. **物理约束与布洛赫球（Physical Constraint and Bloch Sphere）**  
密度矩阵须满足 \(\rho\) 是半正定（positive semidefinite）且 \(\text{Tr}(\rho) = 1\)。进一步推导可以得到：
The density matrix must be positive semidefinite and have unit trace. Further derivation gives:
\[
r_1^2 + r_2^2 + r_3^2 \leq 1
\]
也就是说，布洛赫向量 \(\vec{r}\) 对应在布洛赫球（Bloch sphere）内部或表面。
which means the Bloch vector \(\vec{r}\) lies inside or on the surface of the Bloch sphere.


#### 结论 Conclusion

Any mixed-state qubit density matrix can be represented as

\rho = \frac{I + \vec{r} \cdot \vec{\sigma}}{2}

其中 \(\vec{r}\) 就是布洛赫向量，各分量可通过迹的运算获得，且它的模长不超过 1。
where \(\vec{r}\) is the Bloch vector, its components determined via trace operations, and its magnitude does not exceed 1.

### Question 2

请证明，对于 Shor 九量子比特编码态（Shor’s nine-qubit encoding state），如果前三个量子比特中的任意一个发生了相位翻转（phase flip），则可以通过作用算符 $Z_1Z_2Z_3$ 实现纠错恢复。  
Show that, for the Shor’s nine-qubit encoding state, recovery from a phase flip on any of the first three qubits may be accomplished by applying the operator $Z_1Z_2Z_3$.

#### 1. Shor 九量子比特编码的介绍  
Shor 九量子比特编码（Shor’s nine-qubit code）是一种量子纠错码（quantum error-correcting code），用于保护一个量子比特免受单比特错误（single-qubit errors）的影响。  
The Shor’s nine-qubit encoding is a quantum error-correcting code designed to protect a single qubit from single-qubit errors.

在 Shor 编码中，一个逻辑量子比特（logical qubit）$|\psi_L\rangle$ 被编码为九个物理量子比特（physical qubits）。  
In the Shor code, a logical qubit $|\psi_L\rangle$ is encoded into nine physical qubits.

编码的基本思想是先对一个量子比特进行三重复制（repetition code），然后再对每个复制进行三重编码。  
The basic idea of the encoding is to first apply a three-qubit repetition code, and then further encode each of these using another three-qubit repetition code.

具体地，  
Specifically,

\[
|0_L\rangle = \frac{1}{2\sqrt{2}} \left( |000\rangle + |111\rangle \right)^{\otimes 3}
\]
\[
|1_L\rangle = \frac{1}{2\sqrt{2}} \left( |000\rangle - |111\rangle \right)^{\otimes 3}
\]

其中 $|0_L\rangle$ 和 $|1_L\rangle$ 分别表示逻辑 0 和逻辑 1。  
Here, $|0_L\rangle$ and $|1_L\rangle$ represent the logical 0 and logical 1, respectively.

#### 2. 相位翻转错误的定义  
相位翻转（phase flip）是一种量子错误，通常用泡利 $Z$ 算符（Pauli $Z$ operator）描述。  
A phase flip is a kind of quantum error, usually represented by the Pauli $Z$ operator.

$Z$ 算符作用于量子比特的基矢时，  
When the $Z$ operator acts on a qubit basis state,

\[
Z|0\rangle = |0\rangle,\quad Z|1\rangle = -|1\rangle
\]

也就是说，$|1\rangle$ 态的相位会反转（变成 $-|1\rangle$），$|0\rangle$ 态保持不变。  
That is, the $|1\rangle$ state gets a sign flip (becomes $-|1\rangle$), while the $|0\rangle$ state is unchanged.

#### 3. 前三个量子比特发生相位翻转的情况  
假设第 $i$ 个量子比特（$i=1,2,3$）发生了相位翻转，即 $Z_i$ 作用于编码态。  
Assume that the $i$-th qubit ($i=1,2,3$) suffers a phase flip, that is, $Z_i$ acts on the encoded state.

Shor 编码的结构是，前三个比特是第一个三重编码块。  
In the Shor code structure, the first three qubits form the first triple encoding block.

例如，对 $|0_L\rangle$ 展开后为：  
For example, expanded $|0_L\rangle$ is:

\[
|0_L\rangle = \frac{1}{2\sqrt{2}} (|000\rangle + |111\rangle) \otimes (|000\rangle + |111\rangle) \otimes (|000\rangle + |111\rangle)
\]

#### 4. $Z_1 Z_2 Z_3$ 算符的物理意义  
$Z_1 Z_2 Z_3$ 表示分别对第 1、2、3 个量子比特作用 $Z$ 算符。  
$Z_1 Z_2 Z_3$ means applying the $Z$ operator to each of the first, second, and third qubits.

由于 $Z$ 在 $|0\rangle$ 上不变，在 $|1\rangle$ 上变号，所以 $Z_1 Z_2 Z_3$ 作用在 $|000\rangle$ 上不变，而作用在 $|111\rangle$ 上会变成 $(-1)^3= -1$。  
Since $Z$ leaves $|0\rangle$ unchanged and flips the sign of $|1\rangle$, $Z_1 Z_2 Z_3$ acting on $|000\rangle$ gives no change, and on $|111\rangle$ gives $(-1)^3 = -1$.

即：
That is:

\[
Z_1 Z_2 Z_3 |000\rangle = |000\rangle
\]

所以  
So

\[
Z_1 Z_2 Z_3 (|000\rangle + |111\rangle) = |000\rangle - |111\rangle
\]


#### 5. 纠错机制解析  
假设发生了 $Z_1$ 错误（即第 1 个比特产生了相位翻转），  
Suppose a $Z_1$ error occurs (i.e., phase flip on the first qubit),

\[
Z_1 |000\rangle = |000\rangle,\quad Z_1 |111\rangle = -|111\rangle
\]
所以  
Thus,

\[
Z_1 (|000\rangle + |111\rangle) = |000\rangle - |111\rangle
\]


即码字 $|000\rangle + |111\rangle$ 和 $|000\rangle - |111\rangle$ 之间会互换。  
That is, the codewords $|000\rangle + |111\rangle$ and $|000\rangle - |111\rangle$ swap.

如果我们接着对前三个比特作用 $Z_1 Z_2 Z_3$，  
If we then apply $Z_1 Z_2 Z_3$ to the first three qubits,

\[
Z_1 Z_2 Z_3 (|000\rangle - |111\rangle) = |000\rangle + |111\rangle
\]

这样就恢复了原始的编码态。  
In this way, the original encoded state is restored.

无论前三个比特中的哪一个发生了 $Z$ 错误，$Z_1 Z_2 Z_3$ 都能将错误纠正回来。  
No matter which of the first three qubits suffers a $Z$ error, $Z_1 Z_2 Z_3$ can correct the error.

---

#### 6. 总结  
对于 Shor 九量子比特编码态，前三个比特发生的相位翻转都可以通过作用 $Z_1 Z_2 Z_3$ 算符来恢复。  
For the Shor’s nine-qubit encoding, a phase flip on any of the first three qubits can be corrected by applying the operator $Z_1 Z_2 Z_3$.

这依赖于编码结构：前三个比特为一组，三重编码后，$Z_1 Z_2 Z_3$ 作用实现了错误的纠正。  
This relies on the code structure: the first three qubits form one group, and after triple encoding, $Z_1 Z_2 Z_3$ acts to correct the error.

综上所述，Shor 九量子比特编码通过分组和重复编码，使得任意一个前三个比特的相位翻转都可以通过 $Z_1 Z_2 Z_3$ 纠正。  
In summary, the Shor nine-qubit code, by grouping and repetition encoding, allows any phase flip on the first three qubits to be corrected by $Z_1 Z_2 Z_3$.
